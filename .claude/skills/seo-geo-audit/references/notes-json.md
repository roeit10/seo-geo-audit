# `seo-geo/notes.json`: מה קלוד כותב לדוח

`report.py` לוקח את המספרים רק מקבצי ה-audit. המילים מגיעות מכאן. שדה ריק = הסעיף לא מוצג. אין להכניס מספר
שלא מופיע ב-JSON של הבדיקה.

```json
{
  "business_name": "שם העסק",
  "brand_color": "#1f4fd8",
  "owner_summary": [
    "האתר נמצא בגוגל ו-ChatGPT יכול לקרוא אותו. זה הבסיס, והוא תקין.",
    "החולשה: עמודי השירות לא עונים בראש העמוד מה אתם עושים, ולכן מנועי AI מצטטים אותם פחות.",
    "תיקנו 5 דברים. נשארו 3 החלטות שלך, בתוכנית למטה."
  ],
  "fixed": [
    {"title": "תיאור לגוגל ב-4 עמודים", "why": "זה הטקסט שמופיע מתחת לשם בתוצאות החיפוש. בלי תיאור, גוגל בוחר משפט אקראי.", "where": "lib/seo.ts / Yoast בעמוד X"}
  ],
  "plan": {
    "week": [{"title": "לאשר את השאלות הנפוצות לעמוד הבית", "why": "...", "how": "seo-geo/geo-proposals.md, הצעה 2"}],
    "month": [{"title": "...", "why": "...", "how": "..."}],
    "quarter": [{"title": "פרופיל עסק בגוגל", "why": "...", "how": "..."}]
  },
  "geo_proposals": [
    {"page": "/services", "what": "פסקת תשובה בראש העמוד", "status": "אושר ויושם"},
    {"page": "/", "what": "3 שאלות נפוצות", "status": "ממתין לאישור"}
  ],
  "gbp": "משפט או שניים על Google Business Profile לעסק הזה (מקומי? בלי כתובת? רק המלצה).",
  "snippets": [
    {"title": "Schema של העסק", "where": "Wix: הגדרות SEO של עמוד הבית > Advanced SEO > Structured Data Markup", "code": "{ ... }"}
  ]
}
```

## כללי כתיבה

- **owner_summary:** 3-5 שורות, בשפה של בעל עסק. בלי ראשי תיבות לא מוסברים. משפט ראשון = המצב, משפט אחרון = מה עכשיו.
- **fixed:** רק מה שבוצע ואומת. `why` = התועלת לעסק במשפט אחד (למה זה מביא לקוחות / הקלקות / ציטוטים), לא הסבר טכני.
- **plan:** כל מה שנשאר מ-`fail`/`warn` + הצעות שלא אושרו + המלצות מחוץ לסקיל.
  - **השבוע:** מה שלוקח פחות משעה ותלוי רק בהחלטה (לאשר הצעות, להעלות לאוויר, לשלוח מפת אתר ב-Search Console).
  - **החודש:** תוכן שדורש כתיבה (שאלות נפוצות לעמודים נוספים, alt לתמונות ישנות), Google Business Profile.
  - **ברבעון:** דברים מבניים (עמודי שירות חסרים, מהירות, עמודים יתומים, מעקב ציטוטים ב-AI).
- **gbp:** תמיד קיים. לעסק מקומי: "הצעד הכי משמעותי לחיפוש מקומי". לעסק ארצי/אונליין: "פחות קריטי, אבל עוזר לאמון".
- **snippets:** רק כשאין חיבור לכתיבה, או לתיקון שה-API לא תומך בו.
- בלי מקף ארוך. בלי "מהפכה", "קסם", הבטחות דירוג.

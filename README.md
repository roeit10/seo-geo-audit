# בדיקת SEO ו-GEO לאתר, ותיקון על הפלטפורמה שלכם - Claude Code Skill

רוב בעלי העסקים לא יודעים אם גוגל באמת קורא את האתר שלהם. ועכשיו יש עוד שאלה: האם ChatGPT, Claude ו-Perplexity
יכולים לקרוא אותו ולהמליץ עליכם.

הסקיל הזה בודק את האתר, נותן ציון 0-100, **מתקן אחרי שאתם כותבים "מאשר"**, ומסיים בדוח בעברית עם ציון לפני ואחרי.

- **SEO** = שגוגל ימצא את האתר ויציג אותו טוב.
- **GEO** = שמנועי AI יקראו את האתר ויצטטו אותו. GEO נשען על SEO: רוב מה שמנועי AI מצטטים כבר נמצא גבוה בגוגל.

---

## מה מקבלים

- **ציון 0-100 בשמונה תחומים:** סריקה ואינדקס · גישה למנועי AI · כותרות ותיאורים בגוגל · מבנה כותרות · תמונות וטקסט חלופי
  (alt) · נתונים מובנים (Schema) · תוכן ש-AI מצטט (GEO) · טכני (HTTPS, מובייל, מהירות).
  הציון מחושב בסקריפט. אותו אתר = אותו ציון, בכל ריצה.
- **בדיקה אמיתית של בוטי AI:** הסקיל נכנס לאתר עם ה-User-Agent של ChatGPT, Claude ו-Perplexity ובודק שהם לא נחסמים,
  גם ב-robots.txt וגם בחומת האש.
- **תוכנית ממוספרת** לפני כל שינוי: מה, איפה, היה → עכשיו, ולמה זה טוב לעסק. תיקון במשפט אחד, או "מאשר".
- **תיקון על הפלטפורמה שלכם:**
  - **אתר בקוד** (Next.js, Astro, HTML...): עריכה ישירה בענף נפרד, build לבדיקה, ושום דבר לא עולה לאוויר בלי "מאשר" שני.
  - **וורדפרס:** דרך ה-API, עם סיסמת אפליקציה וגיבוי לפני כל שינוי. עובד עם Yoast ו-Rank Math.
  - **Wix, Shopify, Webflow:** דרך ה-API או Composio, איפה שאפשר. מה שאי אפשר: צעד אחר צעד בעורך.
  - **Framer, Squarespace ואחרים:** קוד מוכן להדבקה והוראות לחיצה אחר לחיצה.
- **הצעות תוכן ל-GEO** (פסקת תשובה בראש העמוד, כותרות בניסוח שאלה, שאלות נפוצות, "עודכן לאחרונה"), בקול שלכם,
  רק מעובדות שאישרתם. **הסקיל לא משכתב עמודים לבד.**
- **דוח HTML ו-PDF בעברית:** ציון לפני ואחרי, מה תוקן, ומה נשאר: השבוע, החודש, ברבעון. עם לינקים לבדיקה עצמית
  (Rich Results Test, Schema Validator, PageSpeed).

## בפעם הראשונה: אשף קצר שמחבר את האתר

הסקיל מזהה לבד על מה האתר בנוי (וורדפרס? Wix? Next.js?) ושואל אם הוא צדק. ואז עובר איתכם צעד אחר צעד על החיבור,
ובודק אחרי כל צעד שהוא עבד:

| האתר שלכם | מה צריך | ביטול |
|---|---|---|
| קוד (תיקייה / גיטהאב) | התיקייה על המחשב, או `gh` מחובר לגיטהאב | למחוק את הענף |
| וורדפרס | סיסמת אפליקציה (Users > Profile > Application Passwords) | Revoke באותו מסך |
| Wix | Composio, או מפתח API עם הרשאת SEO | למחוק את החיבור / המפתח |
| Shopify | Composio, או אפליקציה ב-Dev Dashboard | Uninstall |
| Webflow | Composio, או טוקן אתר | Revoke |

אחר כך: אילו עמודים הכי חשובים לכם, ואישור של עובדות העסק (שם, שירותים, אזור, טלפון). **רק עובדות שאישרתם נכנסות
ל-Schema, לתיאורים ולשאלות הנפוצות.** מה שכבר כתוב אצלכם (`context/business.md`, `CLAUDE.md`, האתר עצמו) הוא לא שואל שוב.
הכל נשמר ב-`context/seo-geo-audit.md`, ומהפעם השנייה ישר לבדיקה.

**סיסמאות ומפתחות** נכנסים לקובץ `.env` שנפתח לכם לעריכה. לא מדביקים אותם בצ'אט.

## הכללים

- **שום שינוי לפני "מאשר".** ולא מעלים לאתר החי בלי "מאשר" נוסף.
- **גיבוי לפני כל כתיבה:** ענף בגיט, או קובץ גיבוי עם הערכים הקודמים.
- **לא ממציאים עובדות.** מה שלא אישרתם לא נכנס לאתר.
- **לא משכתבים תוכן לבד.** רק הצעות, עם היה / עכשיו.
- **כללי ה-SEO לפי Ahrefs**, עם מקור ליד כל בדיקה (`references/ahrefs-rules.md`).

## התקנה ושימוש

1. פותחים Claude Code על **תיקיית המשרד הדיגיטלי** (או כל תיקייה).
2. מדביקים את הלינק לריפו הזה וכותבים: **"תתקין לי את הסקיל שנמצא כאן בפרויקט הנוכחי"**.
3. אם הוא אומר שהסקיל ייטען בשיחה חדשה, פותחים צ'אט חדש.
4. כותבים:

```
תבדוק לי את ה-SEO וה-GEO של האתר שלי
```

או `/seo-geo-audit` והכתובת. בפעם הראשונה: האשף. אחר כך בדיקה (בערך דקה), ציון, ותוכנית שמחכה ל"מאשר".

**טיפ:** באתר בקוד, הריצה הראשונה לא נוגעת באתר החי בכלל: הכל בענף מקומי, ואתם רואים את ה-diff ואת הציון "אחרי" לפני
שמחליטים להעלות.

## מה הסקיל לא עושה

- **לא מבטיח מקום בגוגל או ציטוט ב-ChatGPT.** הוא מסיר חסמים ובונה את התוכן כך שאפשר לצטט אותו. נראות במנועי AI לוקחת
  בדרך כלל 14-21 יום ויותר, ו-SEO קלאסי הוא הבסיס.
- **לא בודק מתחרים וקישורים חיצוניים** (דורש כלים בתשלום).
- **לא מתחבר ל-Search Console** ולא נוגע ב-Google Business Profile. רק ממליץ.
- **לא משפר מהירות** (Core Web Vitals) מעבר להמלצה.
- **לא כותב מאמרים חדשים** ולא יוצר עמודי ערים.
- **לא יוצר llms.txt.** לפי Ahrefs, 97% מהקבצים האלה לא מקבלים אף בקשה.
- **בודק עד 30 עמודים בריצה.** כל העמודים במפת האתר נבדקים רק לסטטוס (עד 300).
